# 无障碍检查清单

## 通用

- 每个交互元素都能用键盘访问：Tab 顺序合理，Enter/Space 触发，Esc 关闭浮层。
- 焦点环必须可见：全局 `:focus-visible` 使用 `2px var(--primary)`；不要 `outline: none` 后不补替代。
- 图标按钮必须提供 `label`（`M3IconButton` 会同时写入 `aria-label` 与 `title`）。
- 纯装饰图标使用 `M3Icon` 默认的 `aria-hidden="true"`；需要语义时传 `label`。

## 对比度

- 正文 / 标题 ≥ 4.5:1；大字号（≥18pt 或 14pt 粗体）≥ 3:1。
- 输入框、按钮边界、焦点环 ≥ 3:1。
- 只使用语义配对：`primary` + `on-primary`、`surface*` + `on-surface*`。
- 深色模式必须单独验证，不得复制浅色模式的透明度假设。

## 表单

- 每个输入都有可读 label（`M3TextField` 浮动标签或 `M3Textarea` 顶部标签）。
- 错误文案放在字段下方，使用 `--error` 且不只靠颜色传达（必须有文字）。
- `inputmode` 与 `autocomplete` 按语义设置：验证码 `numeric` + `one-time-code`，密码 `current-password` / `new-password`。

## 弹窗

- `M3Dialog` 使用 `role="dialog"`、`aria-modal="true"`、`aria-label=title`。
- 打开时锁定 body 滚动；persistent 弹窗仍允许 Esc 忽略（如需强制确认，调用方自行处理）。
- 关闭按钮位于头部右侧，具备 `aria-label="关闭"`。

## 动效

- `prefers-reduced-motion: reduce` 时所有 transition / animation 降为 0.01ms（`base.css` 已统一处理）。
- 不要依赖动画传达状态；状态变化必须有静态视觉结果。

## 触控

- 图标按钮至少 40px，关键操作建议 48px；移动端列表项整行可点。
- 页面在 320px 宽度下不得出现横向滚动（表格允许内部滚动，但需可见滚动提示）。
